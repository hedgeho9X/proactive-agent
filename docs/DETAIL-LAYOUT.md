# 详情展示

截图默认显示所有可定位的标注，固定使用蓝色焦点、橙色选区、绿色点击轮廓，填充强度为零以免遮挡文字。不再提供显示开关、区域选择、颜色或透明度配置。标注尺寸、来源和缺失原因收纳在图片下方的「标注说明」。

点击图片仍可放大，默认适应可用视口；右键保留「复制图片（含标注）」和「复制原图」。固定样式只作用于展示和复制，不改变采集原图或模型输入图。

详情首屏按「AI 理解 → 记录操作 → 截图」排列。「查看 AI 请求详情」收纳模型信息、Prompt、完整输入、AI 看到的图片及原始输出；截图下方的「技术详情」收纳 Action ID、采集诊断、时间、节点数量、AX 属性和原始记录。采集失败的原因仍直接显示，不能因折叠而隐藏。

AI 理解优先读取追踪输出，追踪过期时退回父列表已有的持久化摘要。详情的展示顺序改变不影响理解、投递或采集链路，也不修改任何 Prompt。所有折叠区默认关闭；内容展开后才挂载，AI 追踪轮询同一时刻最多一个请求。

`fixtures/detail-preview.tsx` 提供使用真实组件的合成预览，覆盖正常结果、追踪过期和采集失败，不读取本机历史、不调用模型。浏览器验收包括默认折叠、图像适配、复制菜单及带标注 PNG 请求；剪贴板 IPC 使用替身，不代表本轮重新验证了 macOS 系统剪贴板。静态渲染测试验证摘要顺序、错误状态和默认标注。
