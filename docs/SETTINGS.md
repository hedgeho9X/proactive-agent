# 设置导航

设置采用左侧分类、右侧内容布局，两侧独立滚动。

AI 分类包括模型服务、理解与触发、提示词、网页搜索；应用分类包括观察与权限、桌面弹幕、调试工具。模型服务内仍按屏幕理解、主 Agent、Sub-agent 分别配置。理解并发位于理解与触发，不再混在提示词表单中。

只挂载已访问的分类。设置保持打开时，切换分类或模型角色不丢失未保存的输入；关闭设置后未保存内容不持久化。保存、连接测试、权限申请、采集、搜索凭证与弹幕继续使用原有接口，分类切换本身不保存、不申请权限、不触发模型调用。

合成验收使用 fixtures/settings-preview.ts 挂载真实应用界面，所有 IPC 都由内存替身处理，不使用真实凭证或采集内容。
