# Dock 覆盖层点击归属修复

原逻辑将包含点击坐标的最前窗口直接当作点击目标，可能命中覆盖整屏的 Dock 窗口。

修复后，AX 明确命中 Dock 时保留 Dock；命中其他应用时要求最前非 Dock 候选 PID 一致。AX 不可用时，要求候选为普通窗口，且窗口 PID、前台 PID 和原生事件 PID 三者一致。不确定时返回 dock_overlay_target_unresolved，不将错误窗口截图标记成功。

回归覆盖微信式 AX 缺失、滞后原生 PID、真实 Dock 点击、其他遮挡窗口和自身点击排除。后台窗口首次激活且 AX 不可用时，保守返回失败。

本提交仅包含窗口归属修复、原生回归用例及说明，不包含视口采集、开发应用入口或权限提示改动。真实微信验收由用户自行进行。
