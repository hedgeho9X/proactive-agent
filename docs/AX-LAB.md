# 操作记录与证据详情

入口已合并到原来的“观察与 Agent”主页面，不再显示独立 AX 观测台。操作记录与 Agent 消息按时间排列；点击操作在同一右侧抽屉查看截图、AX 属性、同应用前后 Diff、理解结果和原始记录。截图标记、放大、右键复制、复制 ID、删除和清空功能保留；手动采集入口移入设置。

合并验证：48 项测试、类型检查和构建通过。隔离 Electron 界面确认无独立导航、操作与 Agent 回复同流、记录详情可打开截图并放大，设置默认仅 Enter/Space 勾选。采用标记为模拟操作的已保存测试快照与本地 HTTP 模型服务，Enter、Space 各发出一次含图片的理解请求并收到主 Agent 回复，Tab 的模型调用次数为零。原生自动采集在第一轮测试出现超时，后续单次手动采集成功、真实 Tab 记录成功但未触发模型；因此不把本轮模拟快照链路验证宣称成连续原生采集已完整验收。

原页面“开始观察”统一使用事件采集器，不同时运行旧原始采集循环。设置中的“哪些操作交给 Agent”默认只开启 Enter（含小键盘）和 Space；Tab、Esc、删除、方向键、组合快捷键、鼠标点击可分别启用。选中且证据有效的新记录才进入屏幕理解，再将事实摘要、操作类型、应用、时间、证据 ID 交给主 Agent。此行为会产生模型 API 调用；需要分别配置理解模型和主 Agent。历史 AX 快照不会批量回填分析，未选中操作仍保留本地证据。

触发设置持久保存于 observation-routing.json。队列在理解前、向 Agent 投递前再次检查当前策略和原始记录是否存在；取消选择或删除源记录会阻止尚未投递的分析继续发送。已发出的请求及已进入会话的消息无法撤回。快照按需适配模型输入，不重复复制图片进 observations.sqlite；read_observation 工具可按原 AX ID 读取相同来源。观察摘要取消 intent_hypothesis，Enter/Space 仅作为关注信号，不认定为提交成功。

当前按键策略：过滤普通 A–Z、主键盘与小键盘数字；仅 Shift 大写/数字也过滤。保留 Cmd/Ctrl/Option/Fn 组合键，以及 Enter、Space、Tab、删除、方向、功能和符号键。过滤发生在原生事件入口，历史普通字符记录仍留在磁盘，但列表按新规则筛选。操作列表默认包含未采到证据的有效操作，事件发生与证据成功分别呈现，可取消勾选只看有证据项。

标记默认填充 0%，仅画范围外侧一像素轮廓；完全重合的范围只绘制一次，优先显示点击颜色。绿色空心圈单独标明事件的原始点击坐标，不用大控件框冒充精确点击位置。覆盖窗口超过 60% 的区域注明范围较粗。复制标注图遵循相同规则。原图像素内已有的旧标记或网页自身选中样式不会被自动删除。

窗口一致性：区域所属 AXWindow 必须与截图目标相同才能叠加；无法确认则明确缺失。树根与截图窗口不一致时保留原始证据并标记 alignment.sameWindow=false，禁止直接 Diff，避免将弹窗文字/控件当作主窗口内容。

当前事件取证流程已升级为常驻采集进程、鼠标按下触发、截图请求与 AX 遍历并行。蓝色焦点、橙色选区、绿色点击命中分别验证，区域保存自己的采样来源。时间保证与验证数据见 [事件取证时间边界](EVENT-CAPTURE-TIMING.md)。

从侧边栏进入“AX 观测台”，点击“开始事件记录”后切到其它应用操作，停止后按时间、应用或按键筛选。按键只记录 keyDown；左/右/其他鼠标按下代表一次点击。不再生成 keyUp 和单独修饰键记录，组合键的修饰信息随 keyDown 保留。排除自身，不记录 scroll 或鼠标轨迹。按键名是物理键，不等于输入法最终文本；系统 Secure Input 等限制可能使按键不被系统提供。

每条有效事件先以独立 ID 落盘。按下和点击立即尝试一次 AX/截图采集；重采集忙时仍记录事件并标记 skipped_busy，不补拍过时状态。发生时间与采集时间分别保存，pending/failed/skipped_busy 不伪造采集时间。前台变化、监听中断、存储错误均显式报告。默认视图只显示成功采集的记录，并自动打开最新一条；历史 event_only、失败和忙碌事件仅在勾选诊断后展示，不删除旧数据。

Diff 自动配对同应用、同进程的上一次有证据事件；同毫秒按同一监听 session 的 sequence 排序。跳过无证据 keyDown/click 时显示中间缺失条数，不把它说成紧邻的上一个原始事件。不同窗口仍由对比器阻止硬比较。移除手动基线选择；复制引用包含当前与自动基线的 ID/路径。首次事件无基线时明确显示无更早有效采集。

手动采集已移除三秒倒计时，点击立即执行。快照保存到本应用 userData 下的 ax-snapshots/<ID>/snapshot.json，含属性、状态、trigger 元数据及截图 Base64。独立 meta.json 用于历史列表，初始化通过临时目录原子发布，采集结果更新使用临时文件替换。存储仍为可直接读取的 JSON 历史目录，而非另建数据库。

可从历史重新加载快照，基线自动选取；支持复制 ID、删除当前快照或一键清空历史。“复制 ID”包含当前与基线的绝对文件路径；默认目录为 ~/Library/Application Support/Proactive Agent/ax-snapshots，设置 PROACTIVE_DATA_DIR 时随实例目录变化。删除移至系统废纸篓；清空需要一次确认，逐项报告失败，不影响模型配置、观察流水或 Agent 会话。“清除当前视图”只清理面板，不删除历史。

焦点元素优先读取，随后遍历焦点窗口；焦点窗口不可读时从应用根继续。枚举节点支持的普通属性，分别保存已读取、无值、不支持、失败和预算耗尽状态。支持的动作和参数化属性只列名，不执行动作或盲目调用带参数接口。受保护输入内容及子树不读取。

截图页新增半透明 bbox：蓝色为焦点控件，橙色为非空文字选区，可切换范围、颜色、填充透明度及显隐。原图不修改，标注为本地 UI 图层，不会自动合成进模型输入。原生采集在截图前后读取焦点与选区，控件取 AXPosition/AXSize，文字选区通过已读取的 AXSelectedTextRange 调用 AXBoundsForRange；这是参数化属性读取的明确例外。选区为外接矩形，多行文字不保证逐行贴合；只有光标时不画文字选区。焦点/范围/窗口几何变化时不叠加。

截图点击打开大图，默认 150%，支持 50%–300% 缩放、原始大小和滚动，Esc 关闭。原视图及大图均支持右键菜单：复制当前标注图或复制原图。标注副本按原图分辨率在 Canvas 合成，保留当前颜色、透明度、可见范围设置；通过 Electron 44 的异步 ClipboardItem/clipboard.write 写入 PNG，不改变历史原图。界面实测覆盖放大、标注同步、右键菜单、复制及 Esc 关闭；系统剪贴板读取验证得到 520×282 PNG，与测试源图尺寸一致。

新截图记录 frame（屏幕左上角、逻辑点）、pixelWidth/pixelHeight 和 regions；关闭单窗口阴影，让图像边界对齐窗口范围。前端换算为窗口内百分比并裁剪，可随截图缩放；旧图缺少准确映射，提示重新采集，不猜测补框。受保护焦点仍排除。

预算为最多 800 节点、20 层、约三秒遍历时间；单次属性请求超时 30ms，文本最多 8000 字符，数组序列化最多 100 项。相关截断有标记。遍历预算不含截图时间，单次完整进程最多运行 15 秒。数组展示截断不等于子节点遍历只取前 100 项。各属性分时读取，快照不是原子状态。

截图独立调用 ScreenCaptureKit；能获取 AX 窗口 bounds 时匹配对应窗口，否则仅在目标进程恰有一个可见普通窗口时降级。歧义、权限问题或已发现受保护输入时不返回截图，并显示原因。尚未进行微信实际覆盖率评测，不能因 AX 失败推断反爬。

Diff 左右并排，左侧红色、右侧绿色，并显示行号和匹配依据。优先按应用提供的唯一 AXIdentifier 匹配；其次为唯一角色/标签及父语义，或已匹配父节点下唯一输入控件（标为候选）。不使用顺序路径匹配；焦点预读取后仍恢复控件的真实窗口树路径。应用重启、不同窗口或无有效快照时阻止对比。引用编号、截断和不可序列化属性不当成值变化；读取失败单独标注，未匹配节点不能宣布真实新增/删除。老快照缺少进程启动时间和窗口 ID，跨窗口识别能力有限。可靠控件身份仍取决于目标应用，文本范围读取和手动 AI 解读尚未实现。

建议用自建输入框或 TextEdit 逐项测试：中文输入、删除、粘贴、全选、提交和失焦。先比较屏幕实际变化和 AXValue/AXSelectedTextRange，再测试微信等应用，记录属性错误及覆盖差异。

本轮验证：类型检查、Swift/Electron 构建及 27 项测试通过。独立测试数据目录下的 Electron 实例通过页面交互完成选应用与手动采集，真实 AX 返回 33 节点并成功截图；属性显示无值 -25212 和失败 -25200 的差别。结构化坐标修复后再次采集返回 442 节点、725ms、截图成功。差异测试覆盖临时编号、字典键序、文本变化、读取失败和跨应用隔离。尚未实测微信、中文输入法全过程及系统授权被拒场景。

历史存储补充验证：独立临时目录内使用合成快照验证跨实例读取、完整图片字段、ID 路径约束、符号链接拒绝、删除恢复与清空部分失败。Electron 实际界面验证历史加载、复制 ID 和删除当前快照，测试快照已移入系统废纸篓；没有删除用户业务快照。该合成测试不作为新增的真实 AX 覆盖率证据。

事件与 Diff 补充验证：31 项测试、类型检查与构建通过。原生监听在受控 AppKit 输入窗口实测读到 A、Tab、Enter、Backspace、Escape、Left 的按下/松开，以及点击；只输出该测试窗口的事件元数据，没有记录其余应用正文。存储单测验证三条紧邻事件均保留、忙时跳过重采集、一次采集结果回填原 ID。独立 Electron 实例验证基线选择与左右红绿 Diff，测试文本“明天下午开会”到“明天下午三点开会”仅产生 AXValue 差异；该界面样本为合成快照。尚未完整验证每类真实应用中的输入事件到 AX/截图关联准确率，也不能保证每次按键都有对应完整树。

空记录与基线修复：对用户指定历史目录仅做元数据统计，当时 753 条中有 101 条成功返回节点和截图，398 条旧松开/修饰键事件、246 条忙碌跳过；据此修改默认展示，而不是删除历史或伪造补拍。新单测覆盖只保存 keyDown/click、隐藏空记录、同应用自动基线、跨应用隔离和跳过计数。隔离 Electron 合成五条历史的界面验证默认展示三条有效采集、自动选中最新、连接同应用上次并显示一条缺失，属性和红绿 Diff 正常。

bbox 验证：受控原生 NSTextView 返回焦点 472×140 pt、四字符选区约 47×26 pt，截图成功；在隔离 Electron 载入这份真实采集快照，蓝框对齐文本区，橙框对齐选中的 bbox 四字符，透明度从 22% 调到 40% 生效。坐标测试覆盖窗口偏移、负坐标多屏、裁剪、无效及零面积输入。多屏真机和微信选区支持尚未实测。

字段与遮挡复查：微信某 AX 表情面板有 9 个非空 title、121 个非空 value（含表情名称）、9 个 description；Codex 某样本分别为 12/2/23；浏览器某样本为 8/9/67。不是模型评分或跨应用排名，仅说明不能只取 title。该表情样本的树与截图有窗口错位，不能直接当成同帧理解。文本提取应联合 title/value/description/selectedText，再按节点、角色、窗口、时间和重复内容筛选。

无填充标记验证：隔离 Electron 中实测默认透明填充、外侧细轮廓和空心点击点，右键复制 PNG 的内部采样像素与原图一致、轮廓像素发生变化。另一次自动点击采集超时，未作为成功取证依据；随后独立受控焦点与选区采集成功。持续采集的前台校验和超时仍须按实际状态排查，不能只用 UI 成功推断全链路可靠。
