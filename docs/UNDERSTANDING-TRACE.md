# Understanding 调用链与时序

单条记录 → 查看 AI 请求详情 → 调用链。左侧选择上下文、模型轮次、工具、最终结果或投递；右侧查看 Input、Output、诊断和 Token。工具依靠 toolCallId 关联，旧记录缺失关联时独立展示，不补造历史。

模型轮次和工具开始、结束均保存状态；图片只保存引用，输入图仍从原图片页查看。追踪文件按动作串行、原子替换，避免并行工具写坏 JSON。界面沿用现有 shadcn Button/Tabs。

动作在采集开始前同步占位，完成采集才转入理解。理解保持并发，主 Agent 不得越过仍采集或理解中的前序动作。失败或未选中的采集释放序位；30 秒未完成采集记为超时并放行。旧库已入队顺序不重写；失败重试属于后续补投，不会撤回已投递动作。投递节点保留序位、等待对象、批次和回执时间。

## 2026-09-13 诊断范围

当前可读记录包含 PixPin 两条 keyboard_window_not_found：按键到达时未找到该应用的 AX 焦点窗口或普通层窗口。不能直接断言权限缺失；浮层、窗口关闭和应用未暴露焦点都需要更完整原生证据。

Dock 一条 click_window_owner_ambiguous：WindowServer 命中 Dock 全屏层，AX 命中另一 PID。这是目标归属冲突，不是模型理解失败。另有两条 skipped_busy，是采集并发容量已满。

调查时理解缓存目录已不存在，动作队列为空，无法确认之前模型错误。历史失败不重试、不删除。窗口匹配策略仍需针对真实浮层验证，不能用补拍其他窗口掩盖失败。
