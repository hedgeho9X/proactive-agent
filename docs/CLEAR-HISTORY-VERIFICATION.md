# 全部本地历史清空

2026-09-08：将合并页面残留的「仅清 AX」操作升级为全部历史清理。

## 范围与保护

- 清理 `ax-snapshots`（含截图）、`understanding`、`sessions`、`observations.sqlite` 和 `action-queue.sqlite`；数据库的 WAL/SHM 一并处理。
- 保留 `model-roles.json`、`observation-routing.json`、Electron 配置和 macOS 权限。正常应用内清理也保留内存中的模型 Key，不需要重启；此次从旧版升级重启仍遵循原有的 Key 仅内存策略。
- 主窗口绑定原生确认框；取消不清理。确认后自动停止采集、阻止新修改、等待在途调用，关闭数据库后才开始移动。
- 只移动固定白名单路径，不递归删除数据根目录，不读取或操作其他应用的数据。以整目录重命名取代逐条 AX 快照移到废纸篓。
- 整批移动中途失败会回滚；中途退出后启动时尝试恢复缺失项，遇到冲突拒绝覆盖。旧数据完全移出后才打开新空数据库。
- 废纸篓操作失败时明确保留备份和失败状态；重试只处理已移出的备份，不清理新记录。重启仍能识别待重试备份。
- 清空增加历史版本号，前端忽略旧版本的迟到响应；清空截图详情、AX 列表、旧流水、Agent 事件和理解结果。
- 同一数据目录的新版应用只允许一个实例，避免其他实例写入已移出的数据库。

## 恢复方式

先退出应用。系统废纸篓中的 `history-cleared-<UUID>` 目录包含原目录/数据库及 `manifest.json`。按原名称恢复到 Proactive Lab 数据目录；如果已有新记录，不要直接覆盖，应先保存新数据再人工合并或选择恢复版本。已被旧版逐条移走的快照仍分别留在废纸篓，本次不会清空系统废纸篓。

本轮不修复 `foreground_changed_during_capture` 等采集时序问题。
