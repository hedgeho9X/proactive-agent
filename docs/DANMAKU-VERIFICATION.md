# 桌面弹幕与侧栏收起验证

日期：2026-09-08。

## 实现边界

沿用已有 DSH 主 Agent，不引入第二套 Agent loop。新增链路：工具注册 → sidecar 私有 IPC → RuntimeHost 白名单分发 → Electron 独立透明窗口 → 渲染确认 → 工具结果。

弹幕窗口使用独立 sandbox preload，只暴露弹幕订阅及渲染确认，不暴露主应用通用 IPC；内容通过 `textContent` 展示，不解释 HTML。主进程再次校验长度、时长、频率和开关；同时最多一条，不积压。确认消息必须来自该窗口，ID 必须匹配在途弹幕。动画结束自动移除，宿主另设过期兜底；关闭主窗口同时销毁弹幕窗口。

侧栏沿用 shadcn/Radix Sheet 的外部点击关闭行为；跨应用收起通过 Electron 原生 `blur` → 专用 preload 订阅完成。组件内部焦点变化不被当作离开桌面应用。

## 本次验证

- 全量测试 51 项通过；包括参数边界、缺失桌面时不伪造成功、工具返回状态，以及模拟 OpenAI SSE 模型经过真实 DSH/sidecar 调用宿主回调。
- 类型检查、桌面构建通过。本次变更文件格式检查通过；仓库全量格式检查原有 `src/renderer/ax-stream.ts` 未通过，本次未修改该无关文件。
- 独立 Electron 实例使用临时数据目录，通过真实透明窗口验证了向左移动、原窗口焦点保持、透明背景、无通用 IPC、限频拒绝、禁用后清除。
- 本地 mock 模型经应用内配置 → 主 Agent → `send_danmaku` → 桌面实际动画 → `shown` 工具回执，链路通过。此项是模拟模型响应驱动真实执行，不是线上模型实测。
- 原生侧栏验收：点击窗口内侧栏外部关闭；切换到 Finder 关闭；打开截图预览和右键菜单时侧栏保持。
- 验收工具连接 Electron 时误报空白页，诊断后使用直接 CDP 检查真实窗口。没有使用其他应用的模型凭证。

## 未覆盖

多屏热插拔、所有全屏应用/Space 的置顶兼容、系统减少动态效果实机验收、签名打包后的重新安装均未在本轮完整验证；原生 AX 采集繁忙与时间对齐问题不属于本轮修复。此功能不保证模型每次都主动发弹幕，也不保证用户实际阅读。
