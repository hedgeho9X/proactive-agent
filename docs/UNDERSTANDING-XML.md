# 屏幕理解的 XML 请求

## 证据投影和动态数据边界

`prompts/xml.ts` 将结构化数据序列化后转义 XML 文本字符，避免 AX、OCR、应用名称等内容闭合模板标签。标签用于区分来源，并非安全权限边界；屏幕文字始终不是指令。

`src/model/understanding-evidence.ts` 分别提取点击命中、焦点及选区，不以焦点代替点击。模型接收标准化文本节点和必要 URL／文档属性，不重复接收原始 `raw_nodes` 属性树；非焦点文字仍可保留用于理解场景，不对所有应用统一裁掉侧栏。原始记录不修改，完整属性仍可按 Action ID 查看。

不可用区域保留状态和原因，但不把其失效矩形作为可靠定位。没有 AX 时返回空节点集合，不伪造控件。
