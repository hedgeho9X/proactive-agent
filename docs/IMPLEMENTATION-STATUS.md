## 验收证据要求

确定性模型适配器只能验证运行时契约，必须标 fixture，不计为真实模型通过。

S0 至少记录八项结果：同一主会话两次输入；后台任务未完成时接收修正；child 继续处理；取消请求和停止分开；父子轨迹可归属；非法 Schema 拒绝；proposal 为 not_executed；宿主退出后无残留 runtime。

待应用就绪后，使用受控测试窗口验证：关闭窗口前后证据、Space 播放/暂停、Enter 换行/提交、IME、重复点击、scroll、AX 空壳树、权限缺失与自我排除。不得从旧应用用户数据取样。

真实模型与原生权限项若尚未配置，报告未验证，不用合成数据填成通过。
