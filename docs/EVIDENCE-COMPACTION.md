# 模型证据精简

新请求不再生成或发送 OCR，也不向理解 Agent、主 Agent 注册 OCR 工具。旧 OCR 文件不删除，但兼容读取入口返回 ocr_disabled。截图标注流程仍输出同一帧的 PNG，不再运行 Apple Vision 文字识别。

普通 AX 节点仅向模型提供非空 title、description，相同文本记录去重；空容器、节点 ID、父子层级、role、value 和遍历诊断不进入普通上下文。完整原始 AX 保留在本地详情中。

焦点和点击区域仍独立提供定位证据。输入框正文不当作普通节点属性展开：冻结草稿在 prior_editing_observation 中保留；没有草稿或当前正文不同，才补 current_input。相同正文只发送一次，前后状态不同时不去重。正文来源和时间仍需区分，不能据此宣称发送成功。

## 离线体积对比

2026-09-14 对同一份已保存输入用 SDK 本地 Gemma3 分词器估算，保留相同历史标题：用户消息从 47,340 降至 5,754 Token（约减少 88%），普通 AX 从 412 个节点降至 39 条文字线索。独立草稿保留，OCR 块消失。固定 System 和图片后约为 8.3k 输入 Token；这不是供应商实测账单，也不代表识别准确率验证。

这次不修改标题契约、触发筛选或编辑归并策略，不限制模型输出 Token，也不重跑历史理解。修改后的输入会形成新的缓存键。
