# 窗口 ID 锁定与图片必需契约

2026-09-08，修复前台状态滞后、多个窗口候选导致不截图、空 AX 节点误算成功等问题。

## 采集规则

- 鼠标按下时，按 Window Server 从前到后的窗口顺序和点击坐标锁定窗口 ID，并在 AX 可读时核对所属进程；冲突时明确报错。此事件阶段的系统 target PID 可能仍指向旧前台，因此只记为诊断字段，不能用它过滤真正点到的后台窗口。
- 点击后台窗口时不按旧的前台 PID 过滤。只在自己的弹幕窗口上做已知的点击穿透排除，不把自己的主应用界面当成观察对象。
- 键盘事件在主线程读取前台应用；能读到 AX 焦点窗口边界时优先匹配该窗口，否则选择该应用可见的最前普通窗口，并标明降级来源。
- 事件持久化包含 `targetWindow` 的 ID/PID/frame/source、定位耗时和系统原生目标 PID。随后 ScreenCaptureKit 只接受这个窗口 ID，并复查所属 PID；不在窗口关闭后换拍别的窗口。
- 采集器的前台状态通过 MainActor 读取，避免后台运行循环不推进时状态停留在旧应用。事件已有可靠目标时，之后的前台切换记为警告，不再丢弃所选窗口的图片。
- AX 不再决定能否取得图片。AX 不能关联到目标窗口时允许图片单独成功；不拼入另一个窗口的 AX，也不把不可关联区域的 title 放进图片证据。
- 窗口移动、缩放或无法复查边界时保留窗口图片并明确记录；不叠加坐标关系不可靠的框。保护输入仍遵守原隐私策略。
- 只有 `screenshot.status=captured` 且含图片数据才算采集成功。Recorder、路由和理解服务分别防御；无图不请求模型，不以空节点充数。
- 宿主允许最多 3 路在途采集，减少完整 AX 遍历阻塞后续截图的情况；超过上限明确记录并发占用和失败原因，不积压过时截图请求。

## 故障信息

错误区分事件窗口定位、进程身份验证、窗口可截图性检查、权限、截图 API、编码和 IPC 超时。保留目标 ID/PID、前台读数、候选窗口 ID/边界以及系统错误 domain/code/message，不记录其他窗口标题。

原生进程按请求发出阶段进度，截图和 AX 分别记录状态。即使最终超时，也保留 `lastKnownStages`、超时时长和导致共享采集进程重启的原因。进度使用独立的 `progressFor` 字段，避免旧宿主把它误当成最终结果。

失败记录保留在队列/原始记录视图；过去无图的理解结果不再作为主列表的有效事件。旧事件没有窗口 ID 时要求重新采集，不根据当前桌面补造历史截图。

## 验证

- 单元测试覆盖重叠窗口、同尺寸窗口、后台应用窗口、负坐标屏幕、无窗口命中、目标 ID 校验，以及无图不投递 AI 和三路并发过载诊断。
- 原生测试窗口 A/B 实际接收的窗口 ID，与监听器锁定 ID、最终 PNG 的窗口 ID 三者逐一核对：左键上层 B、左键后层 A 的露出区域、右键 B、Enter A、空格 B，五项全部有图并一致。普通窗口与 floating 窗口均做过验证。
- 切换前台到微信后，手动重放已锁定的测试窗口 ID，仍取得该测试窗口图片；前台读数显示微信，并记录目标保持不变的警告。
- 关闭并释放 B 后请求之前锁定的 B ID，返回 `target_window_closed`，没有改拍仍存在的 A。Window Server 中仍存在但不可见的窗口单独报告 `target_window_not_on_screen`，仍可见但不被 ScreenCaptureKit 提供的窗口报告 `target_window_not_shareable`。
- 微信 PID 2785、窗口 ID 145 的一次只读手动验收得到 1518×848 的 PNG（386435 字节）；未向模型发送，也未在聊天中展示微信内容。
- 完整测试 58 项通过，类型检查、Swift/Electron 构建通过。原生人工验收使用 `tests/native-capture-fixture/main.swift`；它只允许向测试窗口注入输入，目标不明时拒绝发送。

## 边界

无法保证操作系统拒绝录屏、窗口瞬间销毁、受保护输入、特殊透明/非矩形窗口或采集过载时仍然取得图片。保证的是：不选其他窗口来冒充、不把无图当成功、错误可定位。Window Server 查询、AX 和截图不是同一个原子操作，保留各阶段时间用于检查延迟。全屏 Space、多显示器热插拔和快速关闭窗口等情况仍需扩展真实场景覆盖。

独立 Node 宿主下的新建后台测试窗口曾出现截图 API 不返回：进度明确显示 AX 已完成、`screenshot_capture` 仍在执行，最终返回带具体阶段的超时。该场景未当作成功验收；Electron 宿主中的前述输入采集案例已实际取得图片。
