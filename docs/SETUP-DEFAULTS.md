# 初始化与观察授权

首次启动的三个模型角色均使用 OpenAI compatible，Base URL 为 https://example.com/v1/。屏幕理解默认模型为 gemini-3.8-flash；主 Agent、Sub-agent 的模型 ID 留空，由用户之后填写。已有保存配置优先，不覆盖用户配置。API Key 仍由用户显式输入，不预置、不写入配置文件。

OpenAI 根地址请求自动补齐 /v1/chat/completions；已有 /v1 或自定义代理路径保持原前缀。默认配置只是连接预设，不表示该上游已验证支持模型或已完成鉴权。

保存完整配置后，各角色可单独点击“测试连接”，使用该角色内存中的 Key、地址、协议和模型发起固定短文本请求，并显示耗时和脱敏错误。未保存的编辑必须先保存；测试期间锁定表单。测试不上传屏幕或历史内容，仅证明文本生成链路可用，不代表视觉理解、流式返回或工具调用已经通过验收。API Key 不落盘，重启后须重新输入。

观察默认关闭。界面默认选择“所有应用（跟随前台窗口）”，用户点击开始后才采集；也可选择指定应用，Bundle ID 用逗号或空格分隔。观察期间锁定范围选项，停止后修改。空白名单不会被隐式解释为所有应用。采集排除自身应用，保留安全输入、受保护节点和非活跃会话的已有过滤。

辅助功能、屏幕录制、输入监控各有“去授权”入口，由实际 Swift 采集器请求系统权限并打开对应设置。命令先确认收到，再进入系统授权流程，避免等待用户确认导致五秒协议超时。首次打开及从系统设置返回窗口时自动检测权限，也可点击“检测权限”；若系统要求重启，则退出并重开应用。开发版可能归属 Electron，状态显示“采集进程可用”不表示独立打包应用已授权。

独立应用身份为 io.github.hedgeho9x.proactive-agent。验收应从 Finder 启动打包应用，在系统设置核对应用身份并完成授权，再验证真实前台事件、AX、截图和 OCR。编译及协议测试不代替人工系统授权或真实采集验收。
